A two-transistor astable multivibrator, simulated with the step-by-step method from Nuts and Volts' Circuit Simulation Made Easy. It uses an ideal-switch transistor model:

  • ON: \(V_{CE} = V_{CE,sat}\) (0.2 V), and the base-emitter junction clamps the base at \(V_{BE,on}\) (0.6 V).
  • OFF: no collector or base current.

The circuit is symmetric:

  • \(R_A\) is each transistor's collector resistor.
  • \(R_B\) is each base resistor.
  • \(C\) couples each collector to the other transistor's base.
    • \(C_1\) runs from Q1's collector to Q2's base.
    • \(C_2\) runs from Q2's collector to Q1's base.

Method

The only things that carry over from one time step to the next are the two capacitor voltages, since a capacitor's voltage can't jump. They are defined as \(V_{C1} = V_{B2} - V_{C,Q1}\) and \(V_{C2} = V_{B1} - V_{C,Q2}\). Every other voltage follows from those two and from which transistor is ON:

Q1 ON, Q2 OFFQ1 OFF, Q2 ON
Q1 collector\(V_{CE,sat}\)\(V_{BE,on} - V_{C1}\)
Q1 base\(V_{BE,on}\) (clamped)\(V_{CE2} + V_{C2}\)
Q2 collector\(V_{BE,on} - V_{C2}\)\(V_{CE,sat}\)
Q2 base\(V_{CE1} + V_{C1}\)\(V_{BE,on}\) (clamped)

Each capacitor's current depends on which end is free to move:

  • The far transistor is OFF. Its base is free, so all of \(R_B\)'s current charges \(C\). This is the slow timing charge, \(\tau = R_B C\).
  • The far transistor is ON. Its base is clamped, so \(R_A\)'s current flows through \(C\) into that base. This is the fast recovery charge, \(\tau = R_A C\).

Each time step \(n\) goes in this order:

  1. Decide the switch states using only values from step \(n-1\). This is what avoids a circular reference. If the OFF transistor's base reached \(V_{BE,on}\), the pair swaps.
  2. Update the capacitor voltages: \(V_{C,n} = V_{C,n-1} + I_{C,n-1}\,\Delta t / C\).
  3. Work out the node voltages from the table.
  4. Work out the capacitor currents for the next step.

When a transistor turns ON, its collector drops by about \(V\). The capacitor carries that drop straight through to the other transistor's base, which lands near \(-(V - 0.8)\) V and shuts that transistor off. That base then charges back toward \(V\) through \(R_B\), which gives a half-period of:

\[t_{1/2} = R_B C \ln\!\left(\frac{2V - V_{CE,sat} - V_{BE,on}}{V - V_{BE,on}}\right)\]

If \(V \gg V_{CE,sat} + V_{BE,on}\), the fraction inside the log approaches \(2V/V = 2\), and since \(\ln 2 \approx 0.693\):

\[t_{1/2} \approx 0.7\,R_B C \qquad\Rightarrow\qquad T \approx 1.4\,R_B C\]
